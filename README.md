# Hayat - Islamic Life Organizer

## About the Project

Hayat is a simple web application that helps users keep track of their daily Islamic activities and routines.
I created this project to make it easier to stay consistent with daily worship, Quran reading, and other good habits.
The main idea behind this project is to bring useful Islamic features together in one place.

## Features

- Track daily Salah and other worship activities.
- Check prayer times based on the selected location.
- Keep track of Quran reading progress.
- Read duas with Arabic text and translations.
- Browse Islamic content and save favourites.
- Track daily habits and personal goals.
- Write daily reflections and plan for the next day.
- Save supported progress and preferences using Local Storage.

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript


## How to Use

1. Open the live website.
2. Explore the different sections.
3. Update your daily activities and reading progress.
4. Use the tracker to review your progress and maintain your routine.

## Note

The application stores supported data in the browser's Local Storage.
This means saved data usually remains available when using the same browser and website,
but it is not automatically shared across different devices.
This project was developed as a personal project to practise web development and build something useful for everyday life.
